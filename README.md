# Zihntech Academy JavaScript Projects

A collection of interactive JavaScript projects built as part of my learning journey at **Zihntech Academy**.

These projects were created to strengthen my understanding of JavaScript fundamentals, DOM manipulation, events, forms, keyboard interactions, and dynamic webpage behavior.

## 🚀 Projects

### 1. 🎨 The Color Changer
An interactive webpage that allows users to change the background color by clicking a button.

**Concepts practiced:**
- DOM Selection
- Functions
- Click Events
- Variables
- Dynamic Styling

---

### 2. 🌙 Light and Dark Mode
A simple theme switcher that allows users to switch between light mode and dark mode.

**Concepts practiced:**
- DOM Manipulation
- Event Listeners
- CSS Classes
- `classList.toggle()`
- User Interaction

---

### 3. ⌨️ Live Typing Counter
A text input project that counts the number of characters entered by the user in real time.

**Concepts practiced:**
- Input Events
- `.value`
- `.length`
- DOM Updates
- Real-time User Interaction

---

### 4. 🕵️ Key Spy
An interactive project that detects keyboard input and displays information about the key pressed by the user.

**Concepts practiced:**
- Keyboard Events
- `keydown`
- `event.key`
- `event.code`
- Event Handling

---

### 5. 👋 The Welcome Form
A simple form that collects a user's name and displays a personalized welcome message after submission.

**Concepts practiced:**
- HTML Forms
- Form Submission
- Input Values
- `preventDefault()`
- DOM Manipulation
- User Input Handling

---
